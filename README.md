
This repository contains the circuits, design files, Verilog implementations, testbenches, simulation results, and mini-projects I developed during my internship on **VLSI Design Covering Analog and Digital Design Flow**, organized by NIT and NIELIT Calicut.


## 1. Analog Design

The `Analog_Design` directory contains the analog circuit designs and assignments completed during the internship.

The work includes:

- MOSFET Characterization
- CMOS Inverter Design
- Common Source (CS) Amplifier
- Single-Stage CMOS Operational Amplifier
- Two-Stage CMOS Operational Amplifier
- **Analog Mini Project:** Two-Stage CMOS Operational Amplifier

The designs include circuit schematics, simulation results, and relevant design analysis.

## 2. Digital Design

The `Digital_Design` directory contains Verilog HDL implementations, testbenches, and digital design assignments completed during the internship.

The work includes:

- Combinational Logic Design
- Sequential Logic Design
- Counters and Registers
- Finite State Machines (FSM)
- Mealy and Moore Sequence Detectors
- Universal Shift Register
- 8-bit Arithmetic Logic Unit (ALU)
- Code Coverage Analysis
- Logic Synthesis

**Digital Mini Project: Automatic Railway Level Crossing Controller**

The project covers FSM-based RTL design, functional simulation, verification, code coverage analysis, and logic synthesis.
