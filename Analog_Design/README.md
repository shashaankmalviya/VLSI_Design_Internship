# Analog Design Assignments — 01 & 02

This repository contains the completed documentation, schematics, simulation plots, and extracted results for the first two analog design assignments.

## Assignments

| Assignment | Topic | Contents |
|---|---|---|
| [Assignment 01 — MOSFET Characterization](Assignment_01_MOSFET_Characterization/README.md) | PMOS DC characteristics and NMOS threshold-voltage extraction | Testbench schematics, characteristic plots, threshold-voltage plot, and extracted values |
| [Assignment 02 — CMOS Inverter](Assignment_02_CMOS_Inverter/README.md) | CMOS inverter design and performance analysis | Schematic, VTC, switching threshold, noise margins, propagation delay, rise/fall time, and power results |

## Technology and Simulation Environment

- **Technology:** GPDK45 (45 nm)
- **Design and simulation:** Cadence Virtuoso
- **Supply voltage:** 1 V for the circuits documented in these assignments
