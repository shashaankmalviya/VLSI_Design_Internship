# Assignment 3: Code and Display Converters

This assignment covers digital code conversion and seven-segment display decoding.

## Contents

- **Q1:** Converts a 4-bit BCD value to Excess-3 code by adding `0011`.
- **Q2:** Decodes BCD digits 0 through 9 into 7-segment display patterns. Invalid BCD inputs blank the display.

The Verilog modules are under `Q1/src/` and `Q2/src/`; their testbenches are under the corresponding `tb/` directories.
