# Assignment 2: Combinational Building Blocks

This assignment implements frequently used combinational digital-design blocks in Verilog.

## Contents

- **Q1:** An 8-to-3 binary encoder.
- **Q2:** A 4-bit magnitude comparator with greater-than, equal-to, and less-than outputs.
- **Q3:** A 3-bit binary-to-Gray-code converter.

RTL files are in each question's `src/` directory, with matching simulations in `tb/`. The encoder assumes one active input at a time; the comparator produces one asserted relation output for valid binary operands.
