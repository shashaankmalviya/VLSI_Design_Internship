# Assignment 1: Basic Combinational Logic

This assignment introduces common combinational circuits and compares Verilog implementation styles.

## Contents

- **Q1:** AND, NAND, NOR, NOT, OR, XNOR, and XOR gates implemented using dataflow and structural modeling.
- **Q2:** A 2-to-1 multiplexer implemented using gate-level, dataflow, and behavioral modeling.

Each question contains its RTL under `src/` and a corresponding testbench under `tb/`. The testbenches exercise the input combinations and verify the resulting logic outputs.
