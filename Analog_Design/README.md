# Analog Design

A portfolio of analog CMOS circuit designs, academic assignments, and a two-stage CMOS operational amplifier mini project.

The repository documents circuit objectives, design parameters, schematics, simulation setup, measured results, and concise engineering observations.

## Tools

- Cadence Virtuoso
- LTspice

The simulator and process/PDK used are recorded separately for each design. Not every design is assumed to use both tools.

## Repository Organization

Each design has its own folder containing relevant schematics, simulation outputs, results, and calculations. Assignment references are retained in the individual design documentation rather than being used as the primary folder hierarchy.

## How to Navigate

Open the `README.md` inside each design folder for its objective, specifications, circuit description, simulation results, and observations.

## Notes

- Screenshots and plots should be clearly named and placed in the corresponding folders.
- Do not upload proprietary PDK model files, licensed libraries, passwords, license files, or confidential technology files.
- Only verified simulation values should be reported. Missing results are marked as pending rather than estimated.
