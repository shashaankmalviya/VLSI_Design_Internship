# Assignment 5: Sequential Design Blocks

This assignment combines combinational datapath blocks with clocked storage and counting elements.

## Contents

- **Q1:** A 2-to-1 multiplexer.
- **Q2:** A 4-bit magnitude comparator with greater-than, equal-to, and less-than outputs.
- **Q3:** A D flip-flop with a synchronous active-high reset.
- **Q4:** A 4-bit up/down counter with an asynchronous active-high reset.

Every question includes RTL in `src/` and a simulation testbench in `tb/`.
